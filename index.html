📦 MsgPackLens

Paste MessagePack bytes (hex or base64) and see exactly what they decode to - a collapsible tree of the value, and a color-coded byte strip where hovering any byte shows which node it belongs to, and hovering any tree node highlights its exact byte range.

  • Full MessagePack spec: every int/uint/str/bin/array/map width, floats, ext, fixext
  • Canonical minimal encoder (in-page presets are encoded, then decoded)
  • Byte-span tracking per node for the hover sync
  • Precise errors: invalid type bytes, truncation offsets, trailing data, bad UTF-8
  • Verified against the real msgpack library + an independent span walker
